# Debug keys

These keys are for testing the traffic simulation. They work in every build.

| Key           | Action                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------ |
| <kbd>F3</kbd> | Toggle the traffic and parking overlay: stall status, car states and paths, merge windows, HUD metrics |
| <kbd>F4</kbd> | Spawn an errand car at the Walgroins and Taco Hell driveway                                            |
| <kbd>F5</kbd> | Spawn a Taco Hell drive-thru car                                                                       |
| <kbd>F6</kbd> | Spawn a Booger King drive-thru car                                                                     |
| <kbd>F7</kbd> | Spawn a Cramped Inn errand car                                                                         |
| <kbd>F8</kbd> | Spawn a Colonial Plaza errand car                                                                      |
