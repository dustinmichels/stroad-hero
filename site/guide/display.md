# Retro styles and display

## Retro styles

Press <kbd>F1</kbd> to switch to the next visual style and <kbd>Shift</kbd> + <kbd>F1</kbd> to go back. The name of each style appears on screen as you switch.

| Style                | Look                                                       |
| -------------------- | ---------------------------------------------------------- |
| Normal               | The game as modeled, no filter                             |
| Subtle Retro         | Light pixelation that keeps text readable                  |
| 16-Bit Retro         | 3× pixels with a reduced color depth                       |
| 16-Bit Chunky        | 4× pixels                                                  |
| 8-Bit Arcade         | The 16-color PICO-8 palette                                |
| 8-Bit Vivid          | PICO-8 plus its 16 secret colors, with extra saturation    |
| Game Boy Classic     | Four shades of green                                       |
| Amber CRT Terminal   | Amber monochrome terminal                                  |
| CGA Cyberpunk        | Four-color CGA                                             |
| NES Console          | The NES palette                                            |
| 1-Bit Ink            | Black-and-white dithering, after _Return of the Obra Dinn_ |
| Virtual Boy          | Red monochrome                                             |
| Arcade CRT           | Scanlines and screen curvature                             |
| Night Vision Goggles | Green night vision with scanlines, vignette, and grain     |
| Thermal Cam          | Brightness mapped to a heat palette                        |
| Comic Book Halftone  | CMYK halftone dots                                         |

The pixelated styles render the 3D scene at low resolution, then add dithering, outlines, and palette effects on top.

## Render scale

<kbd>F2</kbd> or <kbd>G</kbd> cycles the 3D render scale. Lower scales run faster on slow machines; the HUD stays sharp.

## Time of day

<kbd>N</kbd> jumps the clock between daytime, sunset, and full night, to preview the lighting. Night is never reached during a normal day, which ends at 8:00 PM.
