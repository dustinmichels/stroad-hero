# Controls

Stroad Hero is played with a keyboard. Press <kbd>H</kbd> in the game to see these controls.

## Moving

| Key                                                 | Action                                                           |
| --------------------------------------------------- | ---------------------------------------------------------------- |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Walk, relative to the camera                                     |
| <kbd>Shift</kbd>                                    | Sprint while walking                                             |
| <kbd>Space</kbd>                                    | Hop. Next to a shopping cart, climb in; while riding, climb out. |
| <kbd>P</kbd>                                        | Behind a shopping cart, start pushing it. Press again to let go. |

## Camera

| Key                       | Action                              |
| ------------------------- | ----------------------------------- |
| <kbd>A</kbd> <kbd>D</kbd> | Rotate the camera 45° left or right |
| <kbd>W</kbd> <kbd>S</kbd> | Tilt the camera up or down          |
| <kbd>R</kbd>              | Reset the camera behind Mats        |

## Game

| Key              | Action                               |
| ---------------- | ------------------------------------ |
| <kbd>Enter</kbd> | Answer the phone                     |
| <kbd>C</kbd>     | Open the character customizer        |
| <kbd>Esc</kbd>   | Pause, or resume from the pause menu |
| <kbd>H</kbd>     | Show or hide the controls screen     |

## Display

| Key                              | Action                                     |
| -------------------------------- | ------------------------------------------ |
| <kbd>F1</kbd>                    | Next [retro style](./display#retro-styles) |
| <kbd>Shift</kbd> + <kbd>F1</kbd> | Previous retro style                       |
| <kbd>F2</kbd> or <kbd>G</kbd>    | Change the 3D render scale                 |
| <kbd>N</kbd>                     | Jump between daytime, sunset, and night    |

Developer keys (<kbd>F3</kbd> to <kbd>F8</kbd>) are listed under [Debug keys](./debug).
