# Customizing Mats

Press <kbd>C</kbd> to open the character customizer. The game pauses while it's open, and the preview slowly turns so you can see the backpack.

Use <kbd>↑</kbd> and <kbd>↓</kbd> to choose a row and <kbd>←</kbd> and <kbd>→</kbd> to change it.

| Row      | Options                          |
| -------- | -------------------------------- |
| Headwear | Natural, red ball cap, beanie    |
| Jacket   | Orange, blue, red, green, yellow |
| Backpack | Green, blue, red, yellow         |
| Shoes    | Red, yellow, navy, black, green  |
